# GridMates WS22 — Theme Motifs + Prestige Frames

**Candidate-only:** 16 illustrated motif PNGs + 24 scalable SVG prestige frames (6 shapes × 4 finishes).

Motifs: Woodland (badger, robin, squirrel, stag), Ocean (seahorse, jellyfish, lighthouse, pearl clam), Garden (hummingbird, watering can, sunflower, mantis), Space (astronaut helmet, telescope, comet, spiral galaxy).

Frames: Round, Shield, Portrait, Ribbon, Starburst, Book Crest; Bronze, Silver, Gold, Emerald. These are generic GridMates Core templates, not tied to any in-game achievement or currency.

Artwork was cropped from one transparent source atlas and cleaned for RGB contamination in translucent edge pixels. All 40 candidate assets are catalogued with exact SHA256. Text and unlock statuses belong to native UI.

These are **not yet installed in Word Search, Sudoku or any Android APK**. The painterly illustrations and individual SVG vector styles should be reviewed on 320dp/360dp and at 150–200% fonts before promotion.
