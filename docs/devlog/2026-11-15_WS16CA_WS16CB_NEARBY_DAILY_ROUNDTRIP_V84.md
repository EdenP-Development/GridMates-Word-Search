## WS16CA — Honest Nearby setup and visual cohesion

Based on the owner's v82 phone screenshots, Nearby showed a successful-looking green Host button even when the runtime reported that no usable local Wi-Fi interface was present. The server-side `NearbyCoopRuntime.host()` already rejected absent `localWifiIp()` (wlan/ap interface) before opening a socket. The change exposes `hostNetworkAvailable(): Boolean` with exactly that predicate for the UI, while preserving the authoritative runtime check on the I/O worker. The screen keeps an unsaved `hostNetworkReady` state, disables Host when no usable Wi-Fi/hotspot interface exists or another operation is busy, and presents **Wi-Fi needed to host** with plain-language same-network instructions and an explicit **Check Wi-Fi again** button. On the final Host tap, readiness is checked again to avoid a stale connected snapshot. No internet account/cloud service, no guessed address and no wire-version/network protocol changes. **Caveat:** The current design uses an explicit recheck rather than automatic OS connectivity subscription; reconnects while the screen remains open require tapping Check Wi-Fi again. Joining, manual address, room discovery and join recovery remain accessible independently.

Nearby's status, recovery, hosting, game finder and appearance cards now render via the existing native `GridMatesInfoPanel` parchment/gold frame. Daily Today's card uses the same reusable panel; it still contains its live daily date, progress, play/resume/review button and progress bar. The original lavender-gray plain Cards are removed **from these lobby/landing surfaces only**. No new media assets, giant illustrations, save/bonus rules, or changes to in-game letter-grid art.

App `versionCode=84`, QA `versionName=0.9.40-nearby-daily-cohesion-qa`; existing QA signing and package must be checked on a finished APK. The new `NearbyHostReadinessTest` executable JVM app unit test verifies the readiness/busy gating policy. `test_ws16ca_nearby_daily.py` verifies source behavior and ensures the shared panels keep native buttons/room options and Daily progress.
