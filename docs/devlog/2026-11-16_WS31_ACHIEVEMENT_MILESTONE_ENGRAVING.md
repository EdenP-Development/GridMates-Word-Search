# WS31 — Achievement milestone engraving (v93 QA)

**Scope:** Purely decorative differentiation for advanced achievements, stacked on WS30's verified native icon fix. This is not a new achievement or reward system.

The existing 8 achievements remain exactly as written. Four larger/special accomplishments (20 puzzles, 7 dailies, Hard Solo, all 3 themes) gain a small, original, native Compose engraved laurel detail behind the central symbol and inside the original WS21 shield. Earned accents are antique gold; locked accents are muted. Starter milestones keep the clean shield and symbol. No platform emoji, additional bitmap, external service, profile save, unlock, progress, catalog, or puzzle modification.

CI includes a targeted eight-definition regression test in both Android and art/release pipelines. Android v93 QA is intended to install over v92/v91 with existing signing. Verify on actual phone with locked and earned milestone medals and larger font scaling before approval. Do not promote this QA feature to production or claim device verification based only on compiled instrumentation.
