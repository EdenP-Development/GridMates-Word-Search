## Where it becomes real

- **WS63 source:** `tools/lexicon/ws63_quality_audit.py` generates a deterministic read-only report of source editions, unique identity, chapter/tier eligibility and review warnings, and `test_ws63_quality_audit.py` verifies those rules. **Implemented source, CI still needed** when this crosswalk is authored.
- **WS64 next:** reviewer-ready worksheet and chapter-depth backlog, separated source/owner release gates.
- **WS65+ next:** actual carefully edited candidate vocabulary batches, clear chapter meanings and real board tests.
- **WS71 much later:** repetition-aware selection only if deterministic reconstruction and user tests justify it.

This crosswalk protects both projects: Grid Hunt's research remains attributed and design-specific, while Word Search gets a concrete **quality-lint-and-review workflow** rather than importing unrelated coordinate mechanics.
